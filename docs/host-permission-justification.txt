Winnow analyses reviews on Amazon product pages, so it must read those pages. The content script reads the already-rendered rating, rating histogram and visible reviews, scores them locally, and injects a results panel. Access is limited to Amazon storefront domains. Winnow requests no other site, does not use "tabs", and makes no network requests of any kind - it has no server to send anything to.

The optional localhost/127.0.0.1 permission is not requested at install and is unused by the published extension. Winnow's engine and its optional server are open source; a developer running that server locally can point the extension at it from the options page. That is the only time it is requested, by explicit user action via chrome.permissions.request. Only loopback addresses are accepted; anything else is rejected and never stored, and the service worker independently refuses any non-loopback endpoint. A normal install never holds it and never contacts anything.
